# 会議室予約システム (GAS)

## セットアップ
1. Google スプレッドシートに紐付いたApps Scriptプロジェクトを作り、`Code.gs`と`Index.html`を配置します。
2. `initializeDatabase`を一度実行します。`rooms`、`users`、`reservations`、`cancellations`シートと見出しを作成し、空の`rooms`には固定5室を登録します。
3. `users`シートに社員を登録します。`id`は一意な数値、`status`は`ACTIVE`/`LEAVE`/`RETIRED`、`role`は`MEMBER`/`ADMIN`です。ユーザーIDは画面から直接指定する運用です。
4. Apps Scriptのプロジェクト設定でタイムゾーンを運用地域に合わせます。予約の日付判定と表示に使用します。
5. ウェブアプリとしてデプロイし、社内利用者がアクセスできる設定にします。認証機能は実装していません。

スタンドアロンのApps Scriptで使う場合は、スクリプトプロパティ`SPREADSHEET_ID`に対象スプレッドシートIDを設定してください。

## シート列
各シートの1行目に要件記載の列名を設定します。`rooms`は初期化時、空の場合のみ固定会議室を投入します。定員は要件で値が指定されていないため初期値を`0`としています。社員データは投入しません。

## 未決事項
- 会議室データの`capacity`（定員）の値が未指定です。初期登録では0を仮置きしています。
- 非稼働会議室（`is_active=false`）を予約登録時に禁止する規則は明記されていません。画面の選択肢には表示しませんが、サーバー側で拒否する仕様は追加していません。
- 1日3件の「1日」が予約開始日時の暦日を指すかは明記されていません。暫定的にスクリプトタイムゾーンでの開始日の暦日として数えます。
- 一覧の日付抽出は開始日時の日付で判定します。日をまたぐ予約を各日に表示するかは明記されていません。
- 本人キャンセルの状態条件はF-3に明記されていません。予約済（`BOOKED`）のみキャンセル可能として扱います。
