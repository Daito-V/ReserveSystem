# 会議室の代理キャンセル (GAS)

この成果物に実装している業務機能は、総務部管理者による代理キャンセルだけです。予約一覧、予約登録、本人キャンセル、キャンセル履歴表示の機能および画面は含めていません。

## セットアップ

1. Google スプレッドシートに紐付いたApps Scriptプロジェクトに `Code.gs` と `Index.html` を配置します。
2. `initializeDatabase` を一度実行します。`rooms`、`users`、`reservations`、`cancellations` の各シートと列見出しを用意します。`rooms` が空の場合は固定5室を登録します。
3. `users` シートに社員データ、`reservations` シートに対象予約データを登録します。利用者の `role` は総務部管理者を `ADMIN` とします。
4. ウェブアプリとしてデプロイします。

スタンドアロンのApps Scriptで利用する場合は、スクリプトプロパティ `SPREADSHEET_ID` に対象スプレッドシートIDを設定してください。

## 代理キャンセル

画面で予約ID、実行者ID、理由を指定します。サーバー側で要件に定められた順序で検証し、キャンセル成功時は予約状態を `CANCELED` に変更して `cancellations` に記録します。代理キャンセル処理は `LockService` で直列化します。

会議室の `capacity` 値は要件に具体値がないため、初期登録では `0` を設定しています。社員と予約のデータは事前登録してください。
